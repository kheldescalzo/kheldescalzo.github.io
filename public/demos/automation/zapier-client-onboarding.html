How this would be built

  1. Use a dedicated Google Sheets worksheet with client name, email, status, and a unique client ID.
  2. Trigger on a new row and filter for status Ready. If status changes after row creation, use an updated-row trigger instead.
  3. Look up a durable processed-client record before continuing. The browser demo uses memory only; production needs persistent duplicate protection.
  4. Create a welcome draft in Gmail and a Trello onboarding card with scope, access, hours, and kickoff checklist.
  5. Record the client ID and completed actions. Route errors to manual review so a retry does not duplicate the draft or card.

What to verify before activation: connected accounts, field mappings, available plan features, trigger behavior, duplicate handling, failure retries, and approval of the welcome message. Benefits described here are intended outcomes, not measured client results.
