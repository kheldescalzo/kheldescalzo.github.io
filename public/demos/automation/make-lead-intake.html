How this would be built

  1. Start with a custom webhook accepting name, email, priority, and a unique submission ID.
  2. Validate the required fields. Search Google Sheets for an existing submission ID or normalized email.
  3. Add a lead row only when the lookup has no match. Use sequential processing or a durable idempotency key to avoid simultaneous duplicates.
  4. Use router filters for urgent and standard requests. Send urgent requests to owner review.
  5. Create a Gmail draft for review. Log failures and retry without repeating completed actions.

What to verify before activation: connected accounts, field mappings, available plan features, trigger behavior, duplicate handling, failure retries, and approval of the welcome message. Benefits described here are intended outcomes, not measured client results.
